# Git Workflow

Panduan git workflow PETORA.

## Flow

Use trunk-based development or feature branch model. All changes start from main or release branch, then merge via PR.

## Branch Policy

No direct push to protected branch; PRs require review, tests, and status checks.

## Artifact Rule

Document schema and config changes through migration and documentation update.
