# User Manual

Manual pengguna menjelaskan alur umum untuk user role utama.

## Guidance

Cashiers use POS, staff manage services, vets handle patient records, finance closes cash, and managers review reports.

## Support

If a user cannot access a feature, verify role and branch assignment and contact administrator.
