# Troubleshooting

Panduan troubleshooting untuk permasalahan umum.

## Common Issues

Login failure, slow dashboard, duplicate transaction, failed payment reconciliation, stock mismatch, and missing permissions.

## Method

Verify logs, query the relevant tables, check business rule logs, and trace the failing API. Validate before applying fix.

## Escalation

If issue affects finance, medical records, or security, escalate before performing broad changes.
