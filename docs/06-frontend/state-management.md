# State Management

Dokumen ini mengatur state dan data fetching pada frontend.

## Server State

TanStack Query handles fetching, caching, invalidation, polling, and optimistic updates, especially for branch and transaction data.

## Local State

Use React state or context for transient UI like modal visibility, form wizard steps, and filters.

## Form Validation

Use RHF + Zod schema and adapter for server errors.
