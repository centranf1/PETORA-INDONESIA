# Engineering Handbook

Buku panduan engineering untuk seluruh tim.

## Standards

Follow product requirements, keep business rules explicit, write tests, maintain documentation, and review architecture changes before merging.

## Working Rules

No undocumented feature in production. No service role in frontend. No RLS bypass. No unapproved migration to production.

## Principles

Security, data integrity, observability, maintainability, and usability are mandatory.

All docs in docs directory serve as primary project reference.
