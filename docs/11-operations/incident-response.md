# Incident Response

Dokumen ini mengatur respons saat terjadi insiden.

## Service Impact

Prioritization based on data loss, finance error, unavailable sales, security breach, or branch downtime.

## Response Steps

Identify scope, isolate affected service, preserve evidence, notify stakeholders, restore service, and document root cause.

## Escalation

Critical events escalate to owner, engineering lead, and security contact according to policy.
