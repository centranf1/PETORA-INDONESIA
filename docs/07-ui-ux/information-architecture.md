# Information Architecture

Arsitektur informasi mengorganisir data dan navigasi module.

## Navigation Structure

Dashboard, Customers, Services, Inventory, Sales, Finance, HR, Reports, Settings, and Portal.

## Page Pattern

Every module includes overview, list, detail, create/edit, and related records views performed by role-aware filters.

## Search and Filter

Use search and facet filter patterns for large datasets such as customers, products, bookings, and reports.
