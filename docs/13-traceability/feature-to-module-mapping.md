## Mapping

Dashboard -> dashboard; User & Role -> auth; Customer & Pet -> customer; Sales -> sales; Inventory -> stock; Veterinary -> clinic; Finance -> finance; HR -> payroll; Reports -> analytics; Portal -> portal.

## Guideline

This mapping should be used in backlog planning and module ownership.
