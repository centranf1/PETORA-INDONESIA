# Navigation Structure

Struktur navigasi sistem dibuat untuk kecepatan operasional.

## Sidebar

Group by domain and role. Core items: Dashboard, Sales, Stock, Services, Customers, Clinical, Finance, HR, Reporting, Settings.

## Topbar

Search, branch selector, notifications, user profile, and quick actions for frequently used workflows.

## Responsive

Sidebar collapses to icon view on tablet/mobile; page contents remain accessible via stacked navigation.
