# Change Management

Dokumen ini mengatur perubahan feature dan system baseline.

## Required Updates

Every significant change should update key documents: PRD, workflow, database design, permission matrix, API spec, and test plan as relevant.

## Approvals

Architecture and security changes require approval before rollout. Database changes require migration review.

## Risk Handling

High-impact changes require staged rollout, rollback plan, and stakeholder notice.
