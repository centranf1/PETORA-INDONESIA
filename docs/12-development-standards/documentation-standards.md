# Documentation Standards

Standar dokumentasi teknik dan bisnis.

## Format

Use Markdown, consistent heading levels, diagrams where useful, and metadata blocks for important documents.

## Language

Use Bahasa Indonesia for project docs and English for technical terms when appropriate.

## Quality

No redundant duplication, no undocumented assumptions, and no open decisions masked as final requirements.
