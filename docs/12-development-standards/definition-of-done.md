# Definition of Done

Kriteria selesai untuk item pengembangan.

## Required

Feature meets acceptance criteria, passes tests, has documentation updates, and no unresolved critical issues.

## Quality gate

Updated code uses linting and type checks, and any database or permission change is documented.
