# Definition of Ready

Kriteria siap kerja untuk suatu item backlog.

## Ready Criteria

User story or task has clear requirement, acceptance criteria, role, workflow, data impact, and dependencies. Risks and edge cases are identified.

## Engineering Ready

Implementation plan is clear, environment setup specified, and test approach outlined.

## Security Ready

Permission, validation, and audit requirements have been considered.
