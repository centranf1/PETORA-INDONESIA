# Unit Testing

Unit test fokus pada rule logic dan validation.

## Examples

Price validation, loyalty point conversion, branch assignment, product stock check, overtime payroll calculation, and journal balance.

## Rule

Write tests before or alongside implementation to protect business logic from regression.
